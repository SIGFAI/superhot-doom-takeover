# Doom Takeover

**superhot** × Doom · visual · idea by the team

Bring Doom into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> I turned SUPERHOT into a Doom level: pixelated demons, a shotgun, and fireballs hanging in frozen time until you move.

## Install

Install BepInEx 5 (64-bit) into your SUPERHOT folder, then copy the BepInEx folder from this mod into it and start the game. Walk to move time, press F to fire the shotgun, and grab the green BFG9000.
